# Telco Customer Churn — Supervised Learning Set B

Beginner-friendly project for predicting customer churn using the IBM Telco Customer Churn dataset.

## Files
- `CustomerChurn_SupervisedLearning.ipynb` — practical exam tasks, explanations, Python code and plots.
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` — source dataset.
- `churn_model.pkl` — fitted prediction pipeline (generated by running the notebook).
- `summary_report.md` — report template to complete using your measured results.
- `requirements.txt` — Python dependencies.
- `outputs/` — saved model comparison and sample predictions after notebook execution.

## Run on Windows
1. Install Python 3.10–3.12 (recommended for package compatibility).
2. Open this folder in VS Code or Anaconda Prompt.
3. Create and activate an environment if desired:
   ```bash
   python -m venv .venv
   .venv\\Scripts\\activate
   ```
4. Install packages:
   ```bash
   python -m pip install -r requirements.txt
   ```
5. Start Jupyter:
   ```bash
   python -m pip install notebook
   python -m notebook
   ```
6. Open `CustomerChurn_SupervisedLearning.ipynb` and run all cells from top to bottom.

## Target and business meaning
`Churn = Yes` means the customer left. Recall for the churn class is especially important because false negatives are customers the model fails to flag.

## Important methodological note
SMOTE must be applied only to the training set. For a rigorous final evaluation, put feature engineering, preprocessing, SMOTE, and the estimator into a single imbalanced-learn pipeline and use cross-validation on the original training split. Never oversample the test set.
